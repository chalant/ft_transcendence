  kubectl -n {{ .Release.Namespace }} get pods -w

Then open: https://{{ include "ft.ipAddress" . }}/

{{- else if eq .Values.proxy.service.type "LoadBalancer" }}

The proxy is exposed by a LoadBalancer service on port {{ .Values.proxy.service.port }}:
  kubectl -n {{ .Release.Namespace }} get svc proxy-server
"{{ .Values.ipAddress }}" must resolve to its external IP.
{{- else }}

The proxy service is {{ .Values.proxy.service.type }}. The site only works when served on port 443
at "{{ .Values.ipAddress }}", for example:
  sudo kubectl -n {{ .Release.Namespace }} port-forward svc/proxy-server 443:{{ .Values.proxy.service.port }}
{{- end }}
